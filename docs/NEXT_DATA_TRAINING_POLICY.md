# 다음 데이터의 학습 범위와 하중·위치 출력 방침

2026-09-27 사용자 설명과 후속 권고. **이번에는 설계만 기록하며, 새 데이터가 제공된 뒤
분석·구현·학습한다.** 현재 코드에 이미 적용된 구조가 아니며 기존 모델/설정은 유지한다.

## 사용자 계획과 미확정 항목

- 초기 접촉 ID는 각도뿐 아니라 장력 변화도 거의 없다는 사용자 관찰을 반영한다.
  이번 대화에서 이를 새로 정량 측정한 것은 아니다.
- ID1–18 모두 수집·보존한다. 이전의 초기 ID 소량 수집 우선 제안보다 이번 계획을
  우선한다. 입력 18개 각도는 모두 유지한다.
- 위치와 힘 모델은 별도로 비교·운용하는 방향이다. 원본 접촉 ID를 보존하고,
  우선 실제 위치 출력은 아래/중간/끝단 부근의 세 구간으로 제공한다.
- 제외 ID, 최종 세 구간 경계, 하중 판정 방식/임계값은 미확정이다.
  아래1–9/중간10–15/끝단 부근16–18은 후보이며, 제외 범위에 맞춰 조정한다.

## 초기 ID의 포함 여부

1. 개발 자료에서 ID·자세·방향·실측 힘 크기별로 무부하 대비 입력 반응과 반복성을
   확인한다. 정지는 공통 명령/초기 조건, 사인 운동은 대응 자세·위상을 맞춘다.
   장력이 숨은 단서가 될 것이라고 전제하지 않는다.
2. 전체 ID 기준 모델과 초기 구간을 제외한 후보를 같은 공통 ID validation에서
   비교한다. 전체 및 제외 구간의 결과도 별도로 보존한다.
3. 구분이 어려운 초기 구간은 주요 모델의 지원 범위에서 제외할 수 있다.
   일부 자세/방향만 약하면 조건별 제한도 검토한다. 최종 test를 보고 경계를 고르지 않는다.
4. 변화가 작은 행을 자동 삭제하지 않는다. 제외 ID/조건·세션·표본 수와 정량 근거를
   남기고, 제외 원본은 한계 평가에 보존한다. 입력 각도 채널은 그대로 유지한다.

실제 유부하인데 반응이 없는 표본을 무부하 정답으로 바꾸지 않는다. 제한 범위의
주 모델에서는 미지원 유부하를 제외하고 별도 평가한다. 해당 녹화의 실제 무부하
구간은 운영 조건과 상태 라벨이 확인되면 검출/힘 학습에 사용할 수 있다.
전체 관측 입력이 무부하와 겹치는 접촉은 학습량/후처리만으로 구분을 보장할 수 없다.
학습에서 제외해도 실제 추론에서 자동으로 unknown으로 검출되는 것은 아니며,
지원 밖 접촉을 무부하로 오인할 한계를 함께 보고한다.

## 학습 전 정답 정의와 추론 후 출력 처리를 함께 사용

- 원본 contact_segment_id는 실험 ID로 보존한다. 무부하일 때는 작용 위치의 정답이
  없으므로 그 실험 ID를 위치 학습 정답으로 강제하지 않는다.
- 가능한 경우 실제 외력 제거 구간 기록을 무부하 근거로 사용하고 실측 F/T와 교차
  확인한다. 기록이 없으면 실측 aligned F/T 임계값의 파생 라벨임을 명시한다.
  입력 각도/장력 변화나 모델 예측으로 정답 하중 상태를 만들지 않는다.
- 기존 범위는 |Fx|≤45.4, |Fy|≤43.6, |Fz|≤72.9 mN을 모두 만족하는 상자이다.
  사용자 제공 Kalman 후 1σ 설정이며 평균 신뢰구간이 아니다. 작은 실제 힘도
  범위 안에 들어갈 수 있다. 이번에는 수치를 바꾸지 않는다.
- 새 무부하 기록으로 영점·분산을 확인하고, 상태가 불명확한 전환 구간의 분류 마스크
  여부를 정한다. 누락/NaN은 무부하가 아니다.
- 힘 정답은 무부하에서도 실측 aligned XYZ 그대로 사용한다. 임계값 안이라고 0으로
  덮어쓰지 않는다. 저장 부호 유지, 실제 HRM 제어 코드에서 역정규화 후 -1 적용 유지.

| 표본 상태 | 하중 검출 학습 | ID 학습 | XYZ 학습 |
| --- | --- | --- | --- |
| 지원 범위 유부하, ID 확인 | 사용 | 사용 | 해당 힘 모델 지원 범위에서 사용 |
| 실제 무부하 확인 | 사용 | 제외 | 해당 운영 조건에서 실측값 그대로 사용 |
| 미지원 초기 ID 실제 유부하 | 제한 범위 주 모델에서 제외, 별도 평가 | 동일 | 동일 |
| 상태/ID 불명확 | 확인된 정답 항목만 사용 | 불명확하면 제외 | XYZ 유효·지원 범위이면 사용 가능 |

마스크는 학습용으로 별도 관리하며 원본 라벨을 덮어쓰지 않는다. F/T 정답과 실험 ID는
입력 X에 넣지 않는다. 녹화 분할과 시간 공백을 지키며 모든 모델에 같은 분할을 쓴다.

## 우선 비교할 구조와 최종 출력

- **위치 모델 A:** 센서 입력 → 유부하 확률 + 유부하일 때의 조건부 ID.
  무부하 표본에서는 하중 검출만 학습하고 ID loss는 제외한다. 지원 ID의 원래 번호를
  유지하며, ID를 세 구간으로 합치는 후처리를 적용한다.
- **힘 모델 B:** 센서 입력 → 연속 aligned Fx/Fy/Fz. 위치와 별도로 학습·선택하며,
  유부하/무부하 모두 유효한 힘 정답을 사용한다.
- 현재 끝단 힘 모델은 **ID18 전용**이다. 그 XYZ만으로 몸체 전체의 하중 여부를
  판정하면 안 된다. ID16/17도 끝단 부근 표시에 묶인다고 force 지원 범위가 되지 않는다.
  몸체 힘 확장은 해당 ID 데이터로 별도 학습·검증한 뒤 진행한다.
- 학습 검출기가 반드시 더 좋다고 단정하지 않는다. 지원 범위를 맞춘 상태에서
  학습 검출, 예측 XYZ 임계값, 필요 시 결합을 같은 독립 validation으로 비교한다.
  오경보와 유부하 누락을 함께 보고 선택한다. 히스테리시스 등은 후속 후보이며
  관측 정보 부족이나 힘 추정 편향을 해결하는 수단으로 취급하지 않는다.
- **유부하 출력:** 추정 ID와 세 구간. **무부하 출력:** 표시 ID=0, 구간 없음.
  연속 XYZ와 조건부 ID/확률은 분석용으로 보존하고 raw XYZ를 0으로 강제하지 않는다.
- 위치 확률이 낮다는 것과 무부하는 다르다. 필요 시 위치 불확실을 따로 표시한다.
  이를 ID0으로 바꾸거나 미지원 접촉을 확실히 검출했다고 주장하지 않는다.
- 기본은 기존처럼 추정 ID를 구간에 매핑한다. ID 확률의 구간별 합이나 직접 세 구간
  학습은 이후 비교 가능한 후보이며 이번에 확정하지 않는다.

현재 body 모델은 힘+위치+하중 공동 학습, 현재 추론은 force-box 방식이다.
위치/힘 분리 운용과 위 설계는 아직 미구현이며 성능 우위도 검증되지 않았다.

## 평가와 다음 실행

- 녹화 단위 개발 분할로 모델/임계값을 정하고 test는 격리한다. 새 validation을 이미
  학습한 부모 체크포인트로 검증하지 않는다. 과거/신규 test를 학습에 넣지 않는다.
- 유부하에서의 ID/세 구간 위치 성능, 무부하 검출 오경보/누락, 상태 판정까지 포함한
  전체 성능을 구분한다. 힘 모델은 지원 범위에서 축별 RMSE를 보고한다.
- 기존 Transformer 세 구간 84.04%는 같은 녹화 validation의 실측 기준 유부하 위치
  정확도다. 독립 ID18-only test의 끝단 구간 재현율은 61.04%였다. 전체 세 구간과
  무부하 판정을 포함한 독립 성능 80%가 검증된 것은 아니다.
- 90% 목표는 정한 평가 범위의 독립 test에서 확인한다. 출력 확률 0.9와 실제 90%
  정확도를 동일시하지 않는다.
- 다음 데이터가 오면 라벨/단위/무부하 기록과 녹화 분할을 확인하고, 초기 ID 반응 및
  전체/제외 범위 비교부터 진행한다. 이번에는 문서 외 데이터/코드/모델 변경과 학습 없음.
