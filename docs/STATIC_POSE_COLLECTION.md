# ID별 pan·tilt 3×3 정지 자세 수집 제안

2026-09-27 논의안이며 아직 각도/분할을 실행 설정으로 확정하지 않았다.

- 사용자 제안: tip command pan/tilt 각각0°,15°,30°의9조합을모든ID1–18에서측정하고
  각자세에서여러방향으로힘을가한다. ID와자세를교차시키는방식으로권고한다.
- 기본규모는18ID×9자세=162조건이다. 방향/크기/독립반복을고려하면실제작업량은더많다.
  각조건을한번길게측정하는것이독립반복을대신하지않는다.
- 각도선택: 운용범위가0~30°이면사용자안적절. 기존사인이-35~+35°이고양/음영역을
  모두쓸계획이라면각축{-30°,0°,+30°}의9조합을첫후보로추천한다. 음의자세를
  대칭이라고가정해양의자세로대체하지않는다. 실제허용되는명령조합안에서정한다.
  기존±35°끝점까지검증된다는뜻은아니며필요범위는후속확인한다.
- 각ID에서동일9자세/유사힘방향·크기분포를사용한다. ID마다별도자세만쓰지않는다.
- 각조건: 목표명령고정→안정화→외력제거기준기록→힘증가/유지/제거반복.
  방향과힘크기를바꾼다. 초기장력/제어모드/접촉점/명령각도/반복번호를기록한다.
- 힘방향은aligned hrm_base XYZ측정값으로확인한다. 가능범위에서각축성분과부호를
  다양하게포함하며완벽한단일축힘만수집해야하는것은아니다.
- pan/tilt는명령값이다. 접촉후실제각도는달라질수있으므로실제18상대각과
  wire/loadcell입력, aligned힘정답을계속저장한다. 명령각도를실제각도로대체하지않는다.
- 녹화는가능하면ID×명령자세×반복단위로구분. 같은녹화내자세를변경한다면
  자세구간/안정화/전환시간메타데이터가필요하며현재loader가이를자동분리하지않는다.
- 데이터분할은학습전에녹화단위로정한다. 같은접촉이벤트프레임을랜덤분할하지않는다.
  같은자세의별도반복test(재현성)와학습하지않은자세test(자세일반화)를구분한다.
- 162조건전체전먼저예시ID5/12/18에서9자세씩27조건파일럿을해볼수있다.
  이는기록품질/수집시간점검이며3개ID로전체구간성능을주장하지않는다.
- 기존사인파데이터도유지한다. 정지9자세데이터만으로운동중위치90%를보장하지않는다.
- 현재단계는수집설계논의이다. 코드/입력그룹/원본데이터/모터명령변경없음.

참고: 두요인각3수준은9조합의완전요인설계이며조건수증가에따른비용을고려한다.
